## 配置应用可调试

应用是否支持调试，根据app.json5的debug字段和build-profile.json5的debuggable字段综合判断，app.json5的优先级高于build-profile.json5。
 1. 在app.json5中配置debug字段：
- true：应用支持调试。

2. false：应用不支持调试。

3. 如果没有配置debug字段，则根据build-profile.json5的debuggable字段判断应用是否支持调试。
true：应用支持调试。当[构建模式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-hvigor-compilation-options-customizing-guide#section192461528194916)不是release时，debuggable的缺省值是true，即支持调试。

4. false：应用不支持调试。当构建模式为release时，debuggable的缺省值是false，即不支持调试。

  ## 设置HAP安装方式

  在调试阶段，HAP在设备上的安装方式有2种，可以根据实际需要进行设置。

  
安装方式一：先卸载应用/元服务后，再重新安装。该方式会清除设备上应用/元服务所有的缓存数据。DevEco Studio支持当代码无变化时，不进行推包安装。即根据模块有无变化来判断是否重新推送安装模块包，在运行调试时仅将有变化的模块及依赖它的模块重新推送安装至设备上。如entry依赖了HSP模块，当HSP模块有变化，运行调试时将同时推送安装HSP模块和entry模块。
- 安装方式二：采用覆盖安装方式，不卸载应用/元服务，该方式会保留应用/元服务的缓存数据。

 
设置方法如下：
 
点击编辑器上方![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1a/v3/aMdolE3HTUSxMTz6GegvXw/zh-cn_image_0000002749323708.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=1291F56340D7A8DD9B570F3B5F060B8F128D7D308CE2C51383C639FE1997D8A2)按钮，在菜单中点击**Application**并选择相应模块，点击右侧![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/jthzdT1DSn6Jw9NgWFh-vg/zh-cn_image_0000002749323730.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=5DE2B2856C8099FE17070FD7C0494D6E5D65F3C9D9FDF1743CE3B15BEC53A6FA)按钮打开配置界面。在配置界面**通用**中设置指定模块的HAP安装方式，勾选**保留应用数据**，则表示采用覆盖安装方式，保留应用/元服务缓存数据。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/Y-SkgH1dS-yeb3xpEYd2_A/zh-cn_image_0000002778922797.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=168D365EF63A88049A168831F5F2DA152A83AAFA1F9821188DFBEF477B933807)

 
 

### 配置自定义调试参数

如果未进行自定义，将按默认配置安装和运行应用。如果开发者需要对应用安装、运行等流程增加参数配置，可在**安装参数**和**启动参数**下进行配置。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/kCDatQomS0yaSb6RrE7xsQ/zh-cn_image_0000002778922811.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=97606F6C9F801400299771DF608224B1FBCC93A16180E769A46B50E4571C1AB5)

 
- **安装参数**
**启用源码行跳转**：勾选**启用源码行跳转**表示在构建产物中系统组件增加debugline属性，用于开启[ArkUI 界面检查器源码跳转功能](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-arkui-inspector#section44774145517)。
- **安装标志**：输入bm install命令相关的选项，请参见[bm install 参数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/bm-tool#安装命令install)。如设置"-w 360"，表示将超时等待时间设置为360秒。

 - **启动参数**
**启动**：指定在安装应用后启动的Ability。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/y205TbY_SeiQdb0lm9pTXw/zh-cn_image_0000002778922801.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=5C1183557DD075F4660B1D14DE72D08C04F3AE062C7DF1A98D11D2705D5B097E)


  
**空**：只安装不启动任何Ability。
- **默认 Ability**：默认的EntryAbility，即module.json5文件中配置了“skills”属性的第一个ability；若无配置“skills”属性的ability，则取“mainElement”指定的ability（该ability需存在于“abilities”数组内）；若“mainElement”未指定，则取“abilities”数组内的第一个ability。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d/v3/06pDjSvUTmSTLNFmRYHtlA/zh-cn_image_0000002749483590.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=03EBCD1B0E526FC521C633069922201BDA39B35D388C11AE3A8907C97D421E34)

- **指定 Ability**：工程中的UIAbility或ExtensionAbility。可以在工程中添加UIAbility或ExtensionAbility，详细请参阅[UIAbility开发指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/uiability)或[ExtensionAbility开发指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/extensionability-overview)。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/psy77fXpT2upLkRgs-2tTw/zh-cn_image_0000002749323714.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=B98095D6D04C55DD89525695601C014181445DC4E3A9E2B2EAC28BDD5CEE6662)


 - **启动标志**：输入aa start命令相关的选项，请参见[aa start 参数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/aa-tool)。

## 多模块调试

 

### 安装多个模块

如果一个工程中同一个设备存在多个模块（如存在entry和feature模块），且存在模块间的调用时，在调试阶段需要同时安装多个模块的Hap包到设备中。此时，需要在**多包推送**中选择多个模块，启动调试时，DevEco Studio会将所有的模块都安装到设备上。
 
设置方法如下：
 
点击编辑器上方![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/MUMIwwSiQ5iHK3CAqZI2nA/zh-cn_image_0000002749483602.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=A8D0EA6A29E1DF5FEC531B5758E5C71FC82D4A1C2B073B3E3D0427C14B86DC4E)按钮，在菜单中点击**Application**并选择相应模块，点击右侧![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/SVLOhfWBRNG_43GUUz1_kw/zh-cn_image_0000002779082653.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=A7C94E6016DF5B39E2E4001CC31F55B0B7611E528C6CFEF55537A76FF1F90539)按钮打开配置界面。在配置界面**通用**中，勾选**多包推送**，选择多个模块。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/D8sOWTodQbOsMhLzqFoqsA/zh-cn_image_0000002749323712.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=0B671BB1FAD5D7BDFD09589F496E30470F122918F27FD580D7FBF1E9D28EF288)

 
 

### 自动安装依赖

如果一个工程中entry/feature/HSP模块直接依赖其他HAR/HSP模块（如entry模块依赖HSP模块）及间接依赖其他模块（如entry模块依赖HAR模块，HAR又依赖HSP模块），在调试阶段需要同时安装模块包及其所有依赖模块的包到设备中，此时，可以设置**自动依赖**，启动调试时会自动将所有依赖的模块都安装到设备上。
 
设置方法如下：
 
点击编辑器上方![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/RTsHGP6yQMWxn5SuZw1uVw/zh-cn_image_0000002778922813.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=DEA0A6858CEEF08A31FDFE923AEE175DA5ED9B323B20233D16D08EB3F5221D4F)按钮，在菜单中点击**Application**并选择相应模块，点击右侧![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/v_25t9aUQlCHUIdsEKrKGA/zh-cn_image_0000002749483588.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=623CE2EAAC9F9077475FAFFAE85C341BBBA600325507D99BD17622D47461F776)按钮打开配置界面。在配置界面**通用**中，勾选**自动依赖。**

在**前置任务**中，可以点击![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/M99yX8wzTjqKZfa4SlWZ9Q/zh-cn_image_0000002749323720.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=E588161855F4DD37661BC02BF34127080FB32AD5AE9E1C9F7B2161B3A8D8058C)添加应用启动前的任务，也可以点击![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/VJOyB5z6Tv6dzYldZov0kA/zh-cn_image_0000002749483604.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=20AA6F2AC927D3449C5380499A1B9FDE5B0318D0784F737B31E5DB44FC02BAA9)移除任务。
