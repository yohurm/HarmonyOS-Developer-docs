## 通过DevEco Studio截屏
1. 连接真机设备。
2. 点击鸿蒙电脑DevEco Studio底部![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/0pJufbC5SFmSaU_d6gOF8g/zh-cn_image_0000002749324066.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=3C698C8AD2A949D465A6F880E661BD92D4BB467DF25C9BBD47F599F2D86C1D70)图标打开日志面板，选择HiLog。
3. 点击左侧工具栏中![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/ttEXhjsdRruLP32Xkc2NHQ/zh-cn_image_0000002779083003.png?HW-CC-KV=V1&HW-CC-Date=20261009T012543Z&HW-CC-Expire=86400&HW-CC-Sign=C8025D1236CA97C21A9A574744264476D1A41C4BDC839DEC4C09AC03FDCE3D29)，选择保存路径后即可截取屏幕截图。

## 通过命令行方式截屏

hdc是可以用于调试的命令行工具，通过该工具可以实现截屏功能。更多关于命令行工具hdc的说明请参见[hdc工具使用指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc)。
 
 
```bash
hdc shell snapshot_display -f /data/local/tmp/0.jpeg  // -f参数指定图片在设备上的存储路径，如不指定，会在命令执行完成后显示图片默认存储路径。
hdc file recv /data/local/tmp/0.jpeg  // 将图片从设备发送到本地目录，本示例将图片发送到当前执行hdc命令的目录。
```
