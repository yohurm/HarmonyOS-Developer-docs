# 部署云侧工程

更新时间：2026-10-08 09:38:49

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/agc-harmonyos-clouddev-deploy

您也可选择在云函数和云数据库全部开发完成后，将整个云工程资源统一部署到AGC云端。
 1. 右击云开发工程（“CloudProgram”），选择“Deploy Cloud Program”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/KKtHJUbYSh2lbQ10c8IAUA/zh-cn_image_0000002214858797.png?HW-CC-KV=V1&HW-CC-Date=20261009T012552Z&HW-CC-Expire=86400&HW-CC-Sign=322327BB7F598B0C968F6B6FF3A14137F724E9A92491D0B0ECC5110D15000592)

2. 您可在底部状态栏右侧查看云工程打包与部署进度。请您耐心等待，直至出现“Deploy successfully”消息，表示云工程已成功部署。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/NBLoBJszRzejPpQB6v7UBQ/zh-cn_image_0000002179338472.png?HW-CC-KV=V1&HW-CC-Date=20261009T012552Z&HW-CC-Expire=86400&HW-CC-Sign=2915A4A66E4C979801C442DDEA1A8D5337B0B0514BA52C17005E1A9F5290780D)

3. 在菜单栏选择“Tools > CloudDev”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/ldr1_yVUQJK1pyT-an-BEQ/zh-cn_image_0000002214858789.png?HW-CC-KV=V1&HW-CC-Date=20261009T012552Z&HW-CC-Expire=86400&HW-CC-Sign=F19AC220D9FB48E80EBFF1560AB9B8C54B014BACBA3371C7BB04267E8C5FC362)

4. 在打开的CloudDev面板中，点击“Go to console”，打开当前项目的AGC云开发子控制台。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/2IKDFnrCSvS_aQXHpEkabw/zh-cn_image_0000002179498156.png?HW-CC-KV=V1&HW-CC-Date=20261009T012552Z&HW-CC-Expire=86400&HW-CC-Sign=191B2433460FCF0ACB5408DD15482E7345697867BF1C8FBC6330ADA7CEC86D87)

5. 分别进入云函数与云数据库服务菜单，可查看到您刚刚部署的云函数与云数据库资源。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/5C0G8FoJRYKRxH8dL6binQ/zh-cn_image_0000002467759440.png?HW-CC-KV=V1&HW-CC-Date=20261009T012552Z&HW-CC-Expire=86400&HW-CC-Sign=B2E9BF0FFF5B420B783089C6F380D4D5184331629824F5C6EBCAEDCCB304E563)
