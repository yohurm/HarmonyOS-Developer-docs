# 使用调试器

更新时间：2026-10-08 09:38:49

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-debug-arkts-debugger

Debug界面有三个tab页，分别是“entry”、“entry(PandaDebugger)”和“entry(Native)”。
 
通常第一个tab页“entry”用于展示推包安装过程。
 

![](assets/使用调试器/file-20260514133003937-0.png)

 
第二个tab页“entry(PandaDebugger)”和第三个tab页“entry(Native)”是调试器，用于调试Debugger功能，其中“entry(Native)”仅在涉及Native调试时才会拉起。调试器包含两个窗格，**[Debugger](#section1437520119316)**和**[Console](#section327153017314)**。
 

![](assets/使用调试器/file-20260514133003937-1.png)

 

## Debugger窗格

Debugger显示两个独立的窗格：
 
- 左侧区域是Frames，当应用调试到某个断点时，Frames区会显示当前代码所引用的代码位置。
- 右侧区域是Variables，用于展示当前变量。

 

![](assets/使用调试器/file-20260514133003937-10.png)

 
Debugger窗格有多个按钮： 


> [!NOTE] 说明
> 仅Native调试器中支持该按钮。


| 按钮 | 名称 | 快捷键 | 功能 |
| --- | --- | --- | --- |
| ![](assets/使用调试器/file-20260514133003937-11.png) | Resume Program | F9（macOS为Option+Command+R） | 当程序执行到断点时停止执行，单击此按钮程序继续执行。 |
| ![](assets/使用调试器/file-20260514133003937-12.png) | Step Over | F8（macOS为F8） | 在单步调试时，直接前进到下一行（如果在函数中存在子函数时，不会进入子函数内单步执行，而是将整个子函数当作一步执行）。 |
| ![](assets/使用调试器/file-20260514133003937-13.png) | Step Into | F7（macOS为F7） | 在单步调试时，遇到子函数后，进入子函数并继续单步执行。 |
| ![](assets/使用调试器/file-20260514133003937-14.png) | Smart Step Into | Shift+F7（macOS为Shift+F7） | 代码行存在多个函数嵌套或调用时，可以智能步入选择想进入的方法。 |
| ![](assets/使用调试器/file-20260514133003937-15.png) | Step Out | Shift+F8（macOS为Shift+F8） | 在单步调试执行到子函数内时，单击Step Out会执行完子函数剩余部分，并跳出返回到上一层函数。 |
| ![](assets/使用调试器/file-20260514133003937-16.png) | Stop | Ctrl+F2（macOS为Command+F2） | 停止调试任务。 |
| ![](assets/使用调试器/file-20260514133003937-17.png) | Run To Cursor | Alt+F9（macOS为Option+F9） | 断点执行到鼠标停留处。 |
| ![](assets/使用调试器/file-20260514133003937-18.png) | JSVM Debug Port | 无 | 转发JSVM调试的端口，转发后可以在浏览器的DevTools工具上进行JSVM-API调试。 |
 
 
 
 

### Resume Program

点击Resume Program图标![icon](assets/使用调试器/file-20260514133003937-19.png)，如果存在断点时，命中下一个断点，并展示对应的Frames和Variables信息；如果不存在断点，设备上的应用正常运行，Frames和Variables信息会消失。
 

![](assets/使用调试器/file-20260514133003937-2.png)

 
 

### Pause Program

点击Pause Program图标![icon](assets/使用调试器/file-20260514133003937-3.png)，当有对应源代码时，应用会暂停。
 
 

### Step Over

点击Step Over![icon](assets/使用调试器/file-20260514133003937-4.png)，当前代码执行到下一行代码。
 

![](assets/使用调试器/file-20260514133003937-5.png)

 
 

### Step Into

点击Step Into![icon](assets/使用调试器/file-20260514133003937-6.png)，当前代码进入到方法内部。
 

![](assets/使用调试器/file-20260514133003937-7.png)

 
例如代码进入add方法的定义处。
 

![](assets/使用调试器/file-20260514133003937-8.png)

 

![](assets/使用调试器/file-20260514133003937-9.png)
