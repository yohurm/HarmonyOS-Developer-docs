# 概述

更新时间：2026-10-08 09:38:49

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-previewer-overview

鸿蒙电脑DevEco Studio支持多设备预览器功能，为开发者提供运行和调试HarmonyOS应用/元服务的便捷方式。通过模拟将应用按真实设备分辨率显示在多设备预览器上。这使得开发者无需拥有不同类型的物理设备，就可以在多设备预览器中轻松测试应用程序。多设备预览器无需安装，启动便捷，支持在不关闭当前窗口的情况下切换设备，内存占用更少。通过DevEco Studio自带的多设备预览器，开发者可以更灵活、高效地进行应用开发和调试，提升开发体验与效率。
 

## 设备支持类型

多设备预览器支持的设备类型见下表。
  

| 设备类型 | 设备子类型 |
| --- | --- |
| Phone | Phone直板机 |
| Phone | Foldable双折叠 |
| Phone | WideFold阔折叠 |
| Phone | TripleFold三折叠 |
