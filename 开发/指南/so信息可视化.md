# so信息可视化

更新时间：2026-10-08 09:38:49

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-debug-native-so

在Native调试窗口中，选择**模块**页签，打开模块视图。
 
在Native调试期间，**模块**窗口会列出并显示有关应用使用的so信息。部分属性可按升序/降序来排序，部分属性支持过滤。
