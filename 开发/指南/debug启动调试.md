# debug启动调试

更新时间：2026-10-08 09:38:49

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-debug-arkts-debug

可以按照以下方式启动调试会话。
 1. 如果需要设置断点调试，找到需要暂停的代码片段，单击该代码行的左侧边栏。设置断点后，调试能够在正确的断点处中断，并高亮显示该行。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/YOybynuPRSCtxlNsXquZEg/zh-cn_image_0000002749323860.png?HW-CC-KV=V1&HW-CC-Date=20261009T012525Z&HW-CC-Expire=86400&HW-CC-Sign=B37F03C1E977A897E0C0B4E201BF4C22E7A6F78874D157101C0B0E07D9C98D1E)

2. 在设备选择框中，选择调试的设备。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/-jBbBZW3RH2x704k-sORpA/zh-cn_image_0000002779082797.png?HW-CC-KV=V1&HW-CC-Date=20261009T012525Z&HW-CC-Expire=86400&HW-CC-Sign=A77480F845748B2BFBB3B00ED51AFB041D8F1FC5B21B1758CFBF259D894F23F2)

3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以[配置调试参数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-run-debug-configurations)。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/7vebC3dkTlKCY0ZQtC2qCw/zh-cn_image_0000002749323862.png?HW-CC-KV=V1&HW-CC-Date=20261009T012525Z&HW-CC-Expire=86400&HW-CC-Sign=2BEEAAD9FC27AEE963673A13A9E42FBB02F63625332FC4C09C96D50BDA1BED1C)

4. 在工具栏中，单击调试 ![icon](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/FQIcXLbKQ9aZbAg8t2Yv5A/zh-cn_image_0000002749483738.png?HW-CC-KV=V1&HW-CC-Date=20261009T012525Z&HW-CC-Expire=86400&HW-CC-Sign=FD8257AC9C81DF1FDC1D51C607FA693098E40919D0B05BC30CF07907EAE2366B)。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/aWgesi0wRxeFTzXEvcAB1g/zh-cn_image_0000002749483736.png?HW-CC-KV=V1&HW-CC-Date=20261009T012525Z&HW-CC-Expire=86400&HW-CC-Sign=B1C9542F0B7C425F97E5FE7E847E46A07F0CAB796B558F9D7DDD19CE1F0DA860)

5. 启动调试后，开发者可以通过[调试器](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-debug-arkts-debugger)进行代码调试。如有断点会在断点处高亮，并展示当前断点处的帧和变量。
