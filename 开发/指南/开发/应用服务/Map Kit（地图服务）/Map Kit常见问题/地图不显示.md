# 地图不显示

更新时间：2026-09-09 06:54:05

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/map-faq-1

**现象描述**

无法加载地图。

**可能原因**
1. 无网络。
2. 应用身份校验失败或地图权限未开通。
3. 未完成基本准备工作。

**处理步骤**
1. 检查是否存在日志：get network status error, code: 201, message:Permission denied。日志存在，说明应用缺少获取网络状态的权限。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/2t8L-xsbRCGOQMH6xdrLYA/zh-cn_image_0000002717771866.png?HW-CC-KV=V1&HW-CC-Date=20260911T073009Z&HW-CC-Expire=86400&HW-CC-Sign=1F3EE6ECCFEC36A4D3E961D69712046FDDA74A6C832A31A7458B4935E460BFE0)


  请在应用的module.json5文件中配置获取网络状态的权限。

  
```text
{
  "module" : {
    // ...
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET",
        "usedScene": {
          "when": "always"
        }
      },
      {
        "name": "ohos.permission.GET_NETWORK_INFO",
        "usedScene": {
          "when": "always"
        }
      }
    ]
  }
}
```
请检查应用日志中是否存在日志：The network is unavailable。日志存在，说明设备网络存在问题，请检查网络状态。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/VPnwBg3sTdi0StuP4DxbjA/zh-cn_image_0000002717611934.png?HW-CC-KV=V1&HW-CC-Date=20260911T073009Z&HW-CC-Expire=86400&HW-CC-Sign=3CE62C0997AFA0FB7199DC590DE93074964E4F44951C7074C45AD1F5B52CEC7D)

2. 请检查应用日志中是否存在日志：The app does not have map permission。日志存在，说明应用身份校验失败。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/oOBqezQyQpGln8RxYRPtww/zh-cn_image_0000002747291887.png?HW-CC-KV=V1&HW-CC-Date=20260911T073009Z&HW-CC-Expire=86400&HW-CC-Sign=A5A10958D0D2D600530379993DF4FEF28C4ED09EB9EB89091135051C748D3576)


  查看com.huawei.hms.mapservice进程日志，检查是否存在该日志：App authentication failed. code: 1002600003。参考[1002600003](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-map#section1002600003-应用身份校验失败)完成应用身份校验。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b2/v3/W4m8FbOUTpOFnzru9rK0IQ/zh-cn_image_0000002747211803.png?HW-CC-KV=V1&HW-CC-Date=20260911T073009Z&HW-CC-Expire=86400&HW-CC-Sign=707D087D805EBAD354F84107DBC42CDA27CEF0B927AF8466F9855835151F2803)

3. 请参考“[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)”检查是否完成基本准备工作。
