# 多设备预览器和真机的差异

更新时间：2026-10-08 09:38:49

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hmos-previewer-specification

多设备预览器是一个轻量化的多设备模拟工具，旨在帮助开发者更便捷地调试应用。它直接使用鸿蒙电脑的原生能力，启动更迅速，占用资源更低。由于使用的是鸿蒙电脑的能力，部分Kit或API接口的行为会与真实的手机/平板等设备存在差异。建议开发者在发布应用前，使用真机进行调试以确认最终效果。
 

## 显示效果差异

- 部分UI组件在电脑端与其他设备上的默认样式存在差异，建议显式指定组件样式以保证一致性。
- 部分UI组件在电脑端与其他设备上的显示效果存在差异。

 
 

## Kit能力差异

部分Kit可能不支持在电脑上使用，因此多设备预览器也无法支持，Kit支持的设备类型请参考对应的API 参考文档。
 
 

## 系统能力差异
 

| 功能 | 说明 |
| --- | --- |
| 避让区 | 电脑上没有避让区，因此多设备预览器无法通过API查询手机/平板等设备对应的避让区信息。 |
| 屏幕挖孔 | 电脑和其他设备的挖孔信息不同，因此多设备预览器无法获取到手机/平板等设备的摄像头挖孔信息。 |
| 状态栏 | 多设备预览器无法直接使用电脑上的状态栏能力，无法下滑拉起控制中心或通知中心。 |
| 导航条 | 电脑上没有导航条，因此多设备预览器不支持屏幕底端上滑进入总览或回到桌面等操作。 |
| 应用跳转 | 不支持通过startAbility等接口拉起Release发布的应用。 |
| 设备类型查询 | 通过deviceInfo获取的deviceType始终为2in1，因此通过deviceType区分设备形态来实现多设备UI适配的场景，不适用多设备预览器进行调试。 |
