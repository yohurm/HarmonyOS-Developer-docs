# 数字盾服务术语

更新时间：2026-09-01 03:59:25

## R

  

### Rich Execution Environment (REE)； 普通执行环境

指设备上运行通用操作系统的常规执行环境。
 
  

## S

  

### Secure Element (SE): 安全元件

一种独立、防篡改的专用安全硬件芯片，自带独立CPU、安全存储、加密协处理器、芯片操作系统（COS），和设备主处理器物理隔离。
 
  

## T

  

### Trusted User Interface (TUI)； 可信用户交互

在TEE中运行的安全用户界面，将密码输入、显示和交易确认与普通执行环境（REE）隔离。
