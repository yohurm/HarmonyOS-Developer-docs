**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

定义OH_AbilityRuntime_ConnectOptions结构体类型，用于配置连接ExtensionAbility时的回调选项，包括连接成功、断开连接和连接失败的回调。
