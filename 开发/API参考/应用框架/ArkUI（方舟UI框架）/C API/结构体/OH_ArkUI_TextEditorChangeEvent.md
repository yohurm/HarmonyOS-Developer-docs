## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

定义TextEditor组件文本内容变化事件的结构体，用于在文本内容变化时通知用户，支持获取变化前后的内容等信息，适用于需要在文本内容变化前进行拦截或校验的场景，例如输入拦截、内容过滤、变更确认等。
 
**起始版本：** 24
