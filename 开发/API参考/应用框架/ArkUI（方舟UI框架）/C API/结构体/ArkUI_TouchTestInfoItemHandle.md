## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

定义触摸测试信息项句柄数组，用于聚合触摸命中测试过程中产生的信息项句柄，便于批量访问触摸测试信息。具体接口请参见[native_gesture.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-gesture-h)。
 
**起始版本：** 22
