## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

提供扩展鼠标事件信息的封装类型，用于在鼠标事件回调中获取基础鼠标事件之外的额外鼠标事件属性，适用于需要处理更丰富鼠标交互信息的应用场景。
