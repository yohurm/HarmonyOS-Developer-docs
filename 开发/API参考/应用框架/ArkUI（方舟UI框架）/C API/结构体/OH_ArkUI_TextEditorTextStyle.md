## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

定义文本编辑器的文本样式，支持设置字体、颜色、大小等文本属性，适用于文本编辑器内容样式控制的场景，可帮助开发者灵活定制编辑器中文本的显示效果。例如在富文本编辑器中设置不同段落或文本的字体、颜色、大小等样式。
 
**起始版本：** 24
