## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

定义文本编辑器的属性字符串控制器，支持属性字符串的设置与获取、输入样式设置、光标控制等操作，可用于调整光标位置、设置选区、获取预览文本、向后删除等。
 
**起始版本：** 24
