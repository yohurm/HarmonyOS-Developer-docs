## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

提供手势打断信息类型对象定义，用于在手势打断场景中表示与打断处理相关的信息。关于手势打断信息的相关接口，请参见[native_gesture.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-gesture-h)。
 
**起始版本：** 12
