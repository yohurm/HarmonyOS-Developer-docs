## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

定义路径动画的运动路径配置项，用于配置组件在动画过程中沿指定路径运动的轨迹及相关参数，使组件能够按照预设的运动路径进行位移动画。
