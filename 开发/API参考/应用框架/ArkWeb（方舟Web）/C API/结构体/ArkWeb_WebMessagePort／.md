## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

ArkWeb_WebMessagePort是Web消息端口结构体，表示MessageChannel的两个端口之一，用于发送和接收消息。该结构体支持在Native代码和Web页面之间进行双向消息通信。
