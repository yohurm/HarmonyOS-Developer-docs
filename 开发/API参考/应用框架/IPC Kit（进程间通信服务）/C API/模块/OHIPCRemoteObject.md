## 概述


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

提供远端对象创建、销毁、数据发送、远端对象死亡状态监听等功能的C接口，适用于IPC（Inter-Process Communication，进程间通信）和RPC（Remote Procedure Call，远程过程调用）通信场景。
 
**系统能力：** SystemCapability.Communication.IPC.Core
 
**起始版本：** 12
