## 概述


**支持设备：** Phone | PC/2in1 | Tablet

提供音频编创相关C接口定义。
 
**系统能力：** SystemCapability.Multimedia.Audio.SuiteEngine
 
**起始版本：** 22
 
  

## 文件汇总


**支持设备：** Phone | PC/2in1 | Tablet
 

| 名称 | 描述 |
| --- | --- |
| native_audio_suite_base.h | 声明音频编创相关底层数据结构。 |

| native_audio_converter.h | 声明输入音频格式、输出音频格式底层数据结构和格式转换接口。 起始版本： 26.0.0 |
