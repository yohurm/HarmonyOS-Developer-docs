## 概述


**支持设备：** Phone | PC/2in1 | Tablet

定义一个结构体，用于存储AR Engine中捕获的单帧AR图像数据，包含特定时间戳下的相机图像、追踪状态、锚点及AR相关信息。
 
**起始版本：** 6.1.0(23)
 
**相关模块：** [SpatialRecon](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-spatialrecon)
