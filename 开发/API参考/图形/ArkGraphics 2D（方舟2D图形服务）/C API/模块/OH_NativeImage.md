# OH_NativeImage

更新时间：2026-09-23 02:54:26

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-oh-nativeimage

## 概述

提供NativeImage功能，作为数据消费者，其中一种用法是将数据和OpenGL纹理对接，需在OpenGL环境下使用，另外一种用法是开发者自行获取buffer进行渲染处理。
 
**起始版本：** 9
 
  

## 文件汇总
 

| 名称 | 描述 |
| --- | --- |
| native_image.h | 定义获取和使用NativeImage的相关函数。 引用文件：<native_image/native_image.h> |
