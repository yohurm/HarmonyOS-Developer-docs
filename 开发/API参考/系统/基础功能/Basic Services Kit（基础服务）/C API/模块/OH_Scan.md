# OH_Scan

更新时间：2026-08-29 09:41:17

## 概述


**支持设备：** Phone | PC/2in1 | Tablet

提供扫描模块的 C 接口，支持发现和连接扫描仪、从扫描仪扫描图片、获取图片扫描进度和设置扫描仪参数等功能。开发者可在应用内集成扫描仪相关操作。具体接口说明请参见 [ohscan.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-ohscan-h)。
 
**系统能力：** SystemCapability.Print.PrintFramework
 
**起始版本：** 12
