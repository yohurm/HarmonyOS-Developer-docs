# 概述

更新时间：2026-08-29 09:41:17

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-references/account-api-realname-overview
**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

Account Kit提供了用户实名信息获取和实名信息校验能力，开发者可以通过Account Kit的相关功能，引导用户完成授权并校验其实名信息。
  

## 场景介绍


**支持设备：** Phone | PC/2in1 | Tablet | TV | Wearable

- **获取实名信息**

  应用服务器获取到用户授权后，调用华为账号服务器获取华为账号实名信息。
- **获取用户实名年龄段**

  应用服务器获取到用户授权后，调用华为账号服务器获取华为账号用户实名年龄段。
- **实名信息校验**

  应用服务器获取到用户授权后，调用华为账号服务器校验用户实名信息。
